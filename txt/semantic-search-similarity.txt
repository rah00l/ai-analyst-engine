## **Question 1: What is Semantic Similarity Layer (Embedding-Based)?**

### **The Simple Explanation**

Semantic similarity is the ability to understand that two different phrases **mean the same thing**, even if they use completely different words.

**Examples:**

```
"Payment ID not found" 
  ↕ (similarity score: 0.92)
"Why can't we match payment identifiers?"

"MAPPING ERROR"
  ↕ (similarity score: 0.88)
"The system couldn't map this payment"
```

### **How It Works (Conceptually)**

**Step 1: Convert Text to Numbers (Embeddings)**

Text → **Embedding Model** → Vector of 384 numbers (or 768, or 1536)

```
"Payment ID not found"  → [0.23, -0.45, 0.67, 0.12, ... 384 more numbers]
"Why can't match ID?" → [0.25, -0.42, 0.71, 0.10, ... 384 more numbers]
```

These vectors capture **meaning** in mathematical form. Similar meanings = similar vectors.

**Step 2: Measure Distance (Cosine Similarity)**

$$\text{cosine\_similarity}(A, B) = \frac{A \cdot B}{||A|| \times ||B||}$$

This gives you a number between **-1 and 1**:
- **1.0** = identical meaning
- **0.9** = very similar
- **0.7** = somewhat similar
- **0.5** = loosely related
- **0.0** = completely unrelated
- **-1.0** = opposite meaning

**Visual representation:**

```
Vector A (payment mapping)          Vector B (payment matching)
     ↗                                    ↗
      \ angle = 15°                       \ angle = 18°
       \                                   \
        →                                   →
    
Cosine Similarity = 0.91  (very similar!)
```

## **Question 3: What is Similarity Score?**

### **Definition**

A **similarity score** is a number (between 0 and 1, usually) that measures **how similar two pieces of text are in meaning**.

### **Visual Representation**

```
Similarity Score Spectrum:

1.0 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    │ Identical meaning
    │ "payment ID" vs "payment ID"
    │ Confidence: VERY HIGH ✅

0.92 ┤ "mapping error payment id" vs "why can't match payment?"
    │ Confidence: HIGH ✅

0.75 ┤ "reconciliation" vs "settlement"
    │ Confidence: MODERATE ⚠️

0.50 ┤ "payment" vs "banking"
    │ Confidence: LOW ❌

0.0 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    │ Completely unrelated
    │ "payment" vs "elephant"
    │ Confidence: NONE ❌
```

### **How It's Calculated (Math)**

Using **cosine similarity**, which measures the angle between two vectors:

```
If vector A = [0.5, 0.3, 0.8, 0.2]
If vector B = [0.6, 0.2, 0.9, 0.1]

Dot Product (A·B) = (0.5×0.6) + (0.3×0.2) + (0.8×0.9) + (0.2×0.1)
                  = 0.3 + 0.06 + 0.72 + 0.02
                  = 1.1

Magnitude of A = √(0.5² + 0.3² + 0.8² + 0.2²)
               = √(0.25 + 0.09 + 0.64 + 0.04)
               = √1.02 = 1.01

Magnitude of B = √(0.6² + 0.2² + 0.9² + 0.1²)
               = √(0.36 + 0.04 + 0.81 + 0.01)
               = √1.22 = 1.10

Cosine Similarity = 1.1 / (1.01 × 1.10) = 1.1 / 1.111 = 0.99

✅ Very similar! (0.99 score)
```

```ruby
def find_closest_alias(user_input)
  user_embedding = embed(user_input)
  
  best_match = {
    term: nil,
    confidence: 0,
    alias: nil
  }
  
  # Loop through ALL known aliases
  ALIAS_MAP.each do |alias_phrase, canonical_term|
    alias_embedding = embed(alias_phrase)

        confidence: score,
        alias: alias_phrase
      }
    end
  end
  
  # Only return if confident
  best_match[:confidence] > CONFIDENCE_THRESHOLD ? best_match : nil
end
```

```ruby
# lib/engine/intent/semantic_resolver.rb

require 'rag_embeddings'

module Engine
  module Intent
    class SemanticResolver
      CONFIDENCE_THRESHOLD = 0.85
      MODEL = 'sentence-transformers/all-MiniLM-L6-v2'
      
      def initialize
        # Download model on first instantiation
        RagEmbeddings.download_model(MODEL) unless model_exists?
      end
      
      def resolve(user_input)
        closest_alias = find_closest_alias(user_input)
        return nil if closest_alias.nil?
        return nil if closest_alias[:confidence] < CONFIDENCE_THRESHOLD
        
        # Return intent for the closest canonical term
        Intent.new(
          category: :definition,
          source: "RECONCILIATION_HANDBOOK",
          version: "v2.1",
          section: :definitions,
          term: closest_alias[:term],
          confidence: :high
        )
      end
      
      private
      
      def find_closest_alias(user_input)
        user_embedding = embed(user_input)
        
        best_match = { term: nil, confidence: 0 }
        
        ALIAS_MAP.each do |alias_phrase, canonical_term|
          alias_embedding = embed(alias_phrase)
          similarity = calculate_cosine_similarity(
            user_embedding, 
            alias_embedding
          )
          
          if similarity > best_match[:confidence]
            best_match = {
              term: canonical_term,
              alias: alias_phrase,
              confidence: similarity
            }
          end
        end
        
        best_match[:confidence] > 0 ? best_match : nil
      end
      
      def embed(text)
        # Uses rag_embeddings C extension
        emb = RagEmbeddings.embed(text, model: MODEL)
        RagEmbeddings::Embedding.from_array(emb)
      end
      
      def calculate_cosine_similarity(emb1, emb2)
        # rag_embeddings provides this method
        emb1.cosine_similarity(emb2)
      end
      
      def model_exists?
        # Check if model is already downloaded
        File.exist?(model_path)
      end
      
      def model_path
        File.expand_path("~/.rag_embeddings/#{MODEL}")
      end
    end
  end
end
```

```ruby
# lib/engine/intent/semantic_resolver.rb (Complete)

require 'rag_embeddings'

module Engine
  module Intent
    class SemanticResolver
      CONFIDENCE_THRESHOLD = 0.85
      MODEL_NAME = 'sentence-transformers/all-MiniLM-L6-v2'
      
      def initialize
        @initialized = false
        ensure_model_loaded
      end
      
      def resolve(user_input)
        closest_match = find_closest_alias(user_input)
        return nil if closest_match.nil?
        return nil if closest_match[:confidence] < CONFIDENCE_THRESHOLD
        
        # Build an intent-like result
        {
          term: closest_match[:term],
          alias: closest_match[:alias],
          confidence: closest_match[:confidence]
        }
      end
      
      private
      
      def find_closest_alias(user_input)
        user_embedding = embed_text(user_input)
        return nil unless user_embedding
        
        best = { term: nil, confidence: 0, alias: nil }
        
        Intent::ALIAS_MAP.each do |alias_phrase, canonical_term|
          alias_embedding = embed_text(alias_phrase)
          next unless alias_embedding
          
          similarity = cosine_similarity(user_embedding, alias_embedding)
          
          if similarity > best[:confidence]
            best = {
              term: canonical_term,
              alias: alias_phrase,
              confidence: similarity
            }
          end
        end
        
        best[:confidence] > 0 ? best : nil
      rescue => e
        # Graceful fallback if embeddings fail
        puts "SemanticResolver error: #{e.message}"
        nil
      end
      
      def embed_text(text)
        RagEmbeddings.embed(text)
      rescue => e
        puts "Embedding error for '#{text}': #{e.message}"
        nil
      end
      
      def cosine_similarity(vec1, vec2)
        obj1 = RagEmbeddings::Embedding.from_array(vec1)
        obj2 = RagEmbeddings::Embedding.from_array(vec2)
        obj1.cosine_similarity(obj2)
      end
      
      def ensure_model_loaded
        RagEmbeddings.download_model(MODEL_NAME) unless @initialized
        @initialized = true
      end
    end
  end
end
```
