Stratergy 2 -
Sinatra just turns HTTP → Ruby method → JSON.
Conceptually:
Rails UI
  POST /analyze
        ↓
Sinatra endpoint
        ↓
Engine.analyze(...)
        ↓
ExplanationContract (JSON)
        ↓
Rails renders it

That’s it.
No state.
No database.
No UI logic.
If tomorrow you replace Sinatra with FastAPI:

Engine code stays the same
Only the HTTP adapter changes
